# Essência Nobre Perfumes

Crie um site para a "Essência Nobre", perfumaria de nicho em São Paulo. Mostre os perfumes por categoria (amadeirados, florais, cítricos), conte a história da marca e permita fazer pedidos pelo site. Visual elegante e sofisticado.
